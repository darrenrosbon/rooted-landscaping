# Rooted & Co.

A single-page marketing site for a fictional Portland-area landscaping company. Built as a
design/development portfolio sample, not a real business.

Static HTML/CSS/JS, no build tooling or framework. Front-end only: the quote form has no
backend and simulates a success state client-side.

## Structure

```
index.html
css/styles.css
js/main.js
assets/img/      photography
assets/icons/    inline Phosphor icon sources + favicon
```

## Running locally

Any static file server works, e.g.:

```
python -m http.server 4173
```

Then open `http://localhost:4173`.
